Flotsam2x Experimental - English database, uploaded build only

This is a test candidate. It has passed offline structural checks, but has NOT
been run in the game. It does not change enemy ships or money rewards.

1. Close the game. Back up your save before testing.
2. Extract the Flotsam2x-Experimental folder into runtime\media\mods.
   The resulting path must be:
   mods\Flotsam2x-Experimental\db.spr.en\pirate_sea_ingame_parameter.bin
   Do not put an extra data folder between the mod folder and db.spr.en.
3. Open ShinRyuModManager, enable this mod, and apply/generate the mod load order
   using your installed version's normal procedure. If it reports another mod
   replacing either of the two included tables, disable that conflicting mod
   for the first test.
4. Launch the game in English. Start a fresh voyage / re-enter a sea area.
   Compare the same route with the mod disabled and enabled. Check initial
   flotsam counts, sustained spawns while sailing, and frame rate.
5. To uninstall, disable this mod and regenerate the load order.
   No original files in data need replacing.

Edits:
- max_driftage: 30 -> 60
- min_spawn_time: 7 -> 3.5
- max_spawn_time: 10 -> 5
- initial_spawn_num: 20 -> 40 in 14 named sea-area entries
  (including their _S variants). Blank/test entries are unchanged.

These are database multipliers. Actual visible density depends on placement,
spacing, story conditions and engine limits; exactly twice as many visible
objects is not yet verified. The generic spawn timing fields are inferred to
belong to driftage from their context; watch for unintended sea activity changes.

Report whether the game launches, whether new voyages have more flotsam,
whether there is a noticeable performance cost, and any unexpected behaviour.

The included patch-manifest.json records every edited field and byte offset.
