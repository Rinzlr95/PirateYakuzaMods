FlotsamLoot2x - ITEMS ONLY TEST

This test doubles the 16 positive item quantity entries in the
pirates_driftage reward category. Examples:
  Components: 3 -> 6
  Quality Components: 2 -> 4
  Superb Components: 1 -> 2
  Fishing Net: 2 -> 4

Cash is NOT implemented: all direct money/money_end fields in this reward
category are zero in the uploaded database. No new cash reward is invented.
This is not advertised as a completed 2x items AND 2x cash mod.

Spawn positions, frequency, initial population, item IDs, reward odds,
shop prices, selling prices and other reward categories are unchanged.
Only one loose game file is included: db.spr.en/reward_table.bin.
The file contains the original other reward categories, so another mod
changing any category in reward_table.bin conflicts at file level.

INSTALL
1. Close the game and back up your save.
2. Disable Flotsam2x-Experimental (the earlier density mod) for this test.
3. Extract FlotsamLoot2x-ItemsOnly-Test into runtime\media\mods.
   Expected path:
   mods\FlotsamLoot2x-ItemsOnly-Test\db.spr.en\reward_table.bin
4. Enable the new mod in ShinRyuModManager and generate/apply the load order.
   Check for conflicting reward_table.bin overrides.
5. Restart the game in English and begin a new voyage.

TEST
Compare inventory totals before and after picking up one piece of flotsam.
Prefer Components or Quality Components, below the inventory cap. Check the
actual inventory increase as well as the popup; capped inventory can hide gains.
Expected database rewards are 6 Components or 4 Quality Components per matching
pickup, instead of 3 or 2. Actual game behaviour has not been verified here.

UNINSTALL
Disable the new mod and regenerate the load order. Original data files remain
untouched. Items already awarded remain in your save.

VALIDATION
Original archive hash checked. All 16 original field values checked, only their
quantity bytes changed, table length preserved, and ZIP payload verified.
Game launch, loader behaviour and in-game awards still require local testing.
